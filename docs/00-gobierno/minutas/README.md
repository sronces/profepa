# Minutas y acuerdos

Esta carpeta concentrará las minutas que originan cambios en procesos,
requerimientos, reglas o arquitectura.

Para cada minuta se recomienda registrar:

- fecha;
- participantes;
- acuerdos;
- responsables;
- fecha compromiso;
- requisito/regla/proceso afectado;
- evidencia;
- estado.
