# Control de versiones

## Esquema

- `main`: línea controlada.
- `develop`: integración de cambios, si se decide habilitarla.
- `feature/*`: cambios funcionales o técnicos.
- `docs/*`: cambios exclusivamente documentales.

## Versionado recomendado

`MAJOR.MINOR.PATCH`

- MAJOR: cambio estructural o baseline mayor.
- MINOR: nueva funcionalidad/requisito compatible.
- PATCH: corrección documental menor.
