# Guía de contribución

## Flujo recomendado

1. Crear una rama para el cambio.
2. Modificar únicamente los artefactos relacionados.
3. Actualizar la matriz de trazabilidad cuando corresponda.
4. Registrar decisiones técnicas mediante ADR.
5. Crear Pull Request.
6. Solicitar revisión funcional/técnica.
7. Integrar a `main` después de aprobación.

## Convenciones

- Usar identificadores únicos.
- No eliminar requisitos sin registrar el motivo.
- Evitar cambios silenciosos en reglas de negocio.
- Mantener archivos fuente editables de diagramas.
- No incorporar información sensible o secretos.
