# ADR-001 — Arquitectura API-first

- **Estado:** Propuesta inicial
- **Fecha:** 2026-09-01

## Contexto

La plataforma requiere interoperabilidad con sistemas externos y separación clara
entre aplicaciones, servicios y datos.

## Decisión propuesta

Adoptar un enfoque API-first para las integraciones, con interfaces documentadas,
versionadas, autenticadas y observables.

## Consecuencia

Las integraciones deberán definirse como contratos técnicos verificables y no como
dependencias informales entre componentes.
